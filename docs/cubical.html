2. 有限立方體類型

2.1 定義（CubeTy）

一個 維有限立方體類型係面偏序 上嘅一個預層圖式：每個子立方體 一個有限集（以基數 card[σ] 表示，元素編碼做 嘅整數），每個面包含 一個限制映射

一個「上下文入面嘅元素」就係泛型子立方體上面嘅元素 ；佢所有面都係限制。CubeTy::check 窮舉驗證預層兩律。有限集之間嘅映射一律用圖表陣列表示；有限集等價（isomorphism）以 Iso { dom, cod, fwd, bwd } 表示，並有決策程序 fn_inv：有限集來講， 可判定且等價於 係雙射。
